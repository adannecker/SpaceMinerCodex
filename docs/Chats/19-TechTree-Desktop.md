Die Wege können sich ergänzen: Aus einer beschädigten Maschine bergen wir einen funktionierenden Motor, demontieren die Kabel und verarbeiten den unbrauchbaren Rahmen.

**Deine Forschungsbedingung würde ich genau am Rohstoffausgang setzen.** Für beispielsweise Lithiumrückgewinnung braucht man:

- erforschtes **Lithiumwissen**,
- eine identifizierte **Akkuchemie**,
- ein dazu passendes **Rückgewinnungsverfahren**,
- die nötige Anlage, Energie, Hilfsstoffe und Lagerplätze.

Fehlt das Wissen, bleibt der betreffende Anteil als **unbekannte beziehungsweise noch nicht verarbeitbare Materialfraktion** erhalten. Im Overlay steht dann etwa: „Lithiumrückgewinnung gesperrt: Stoffwissen fehlt.“

Ein geprüftes vollständiges Akkumodul könnte dagegen bereits verwendet werden, sobald Funktion und Kompatibilität bekannt sind. Seine gesamte Herstellungskette muss dafür noch nicht beherrscht werden.

Zwei Beispiele für die Verzweigungen:

**Hüllenplatte:**
Bergen → prüfen → aufarbeiten → wieder einbauen.
Oder: Beschichtungen abtrennen → Legierung sortieren → aufbereiten → neue passende Bauteile fertigen.

**Akkupaket:**
Bergen → prüfen → vollständig weiterverwenden.
Oder: zerlegen → geeignete Zellen und Elektronik erhalten → unbrauchbare Reststoffe gezielt recyceln.

Der letzte Schritt muss nicht immer ein reines Element liefern. Bei Akkurecycling können beispielsweise nutzbare Lithiumverbindungen oder erhaltenes Elektrodenmaterial entstehen. Das spart weitere Herstellungsstufen. [Argonne: Recyclingwege](https://publications.anl.gov/anlpubs/2019/07/153050.pdf)
